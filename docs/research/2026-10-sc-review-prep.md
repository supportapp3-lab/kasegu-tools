## 10/20以降の確認手順

- Search Consoleの「検索パフォーマンス」で検索タイプをウェブにし、ページ別に表示回数・クリック数・平均掲載順位・クエリを確認する。対象期間と比較期間を画面に記録し、数値が出ない項目は「未確認」とする。
- 各ページのクエリを表のパス・title・h1・推定意図と照合する。ページの役割とクエリが合うか、複数URLに同じクエリが出るかを記録する。短い期間の変動だけで原因や売上への効果を断定しない。
- 「ページのインデックス登録」で未登録URLと表示された理由を確認する。URLを表のパスに対応づけ、サイトマップ掲載、内部リンク、該当するページ種別を照合する。画面にない理由は「未確認」と記す。
- 記録は観測日・対象期間・画面で確認した値を分ける。Search Consoleにまだデータがない場合は、ゼロと未確認を混同せず「未確認」と記す。

| 観測した状態 | 次に検討する小さな改善Issue | 判断時の注意 |

| 表示回数がありクリックが0 | 該当URLのtitle・descriptionがページ内容とクエリに合うかを点検する | 期間、表示回数、クエリを記録し、少数データで断定しない |
| 想定と異なるクエリで表示 | ページのh1・本文で不足する説明や、対象読者のずれを点検する | 一時的なクエリだけで本文を大きく変えない |
| 同じクエリで複数URLが表示 | URL間の役割分担と内部リンクの案内先を点検する | すぐ統合・削除せず、各ページの目的を照合する |
| インデックス未登録が目立つ | 内部リンク、サイトマップ記載、表示された未登録理由を確認する | Search Consoleの具体的な理由を記録してから対処する |
| 表示がほぼない、またはデータが未確認 | 計測期間と登録状況を再確認し、既存ページを強化する必要性を判断する | 新しい広い防災記事やURLを増やさず、判断材料が足りなければ待つ |

改善を検討するときも、新しい広い防災記事やURLは増やさず、既存URLの役割を明確にする範囲に限定します。

## アソシエイト申請判断との関係

申請時期の推奨や断定はしません。利用者と相談して決める前提で、判断材料として次のSearch Console指標を確認します。

- 表示回数とクリックの有無、およびその対象期間
- 購入枠（表の `data-category` があるページ）への検索流入の有無
- 該当する流入クエリと、ページ内容・購入枠の役割との整合性

これらは申請可否や売上を保証する指標ではありません。計測結果がない場合は「未確認」とし、他の申請条件は別途公式情報で確認します。

## 取得方法と再現

基準コミットの `sitemap.xml` に記載された40個のURLを起点にし、各URLに対応するHTMLを同じコミットから取得しました。パスはサイトの `/kasegu-tools/` 接頭辞を除いた相対パスです。タイトル、h1、description、購入枠のカテゴリはHTMLから機械的に抽出し、検索意図とカニバリ候補だけを本文の主題に基づいて手作業で推定しました。次の依存関係のないPythonスクリプトでローカルのチェックアウトを再確認できます。

```bash
python3 - <<'PY'
from html.parser import HTMLParser
from pathlib import Path
from xml.etree import ElementTree

root = Path(".")
ns = {"sm": "http://www.sitemaps.org/schemas/sitemap/0.9"}

class Metadata(HTMLParser):
    def __init__(self):
        super().__init__(convert_charrefs=True)
        self.title = self.h1 = self.description = ""
        self.categories = []
        self.capture = None
        self.affiliate = 0

    def handle_starttag(self, tag, attrs):
        attrs = dict(attrs)
        if tag == "title":
            self.capture = "title"
        elif tag == "h1":
            self.capture = "h1"
        elif tag == "meta" and attrs.get("name", "").lower() == "description":
            self.description = attrs.get("content", "")
        if "affiliate" in attrs.get("class", "").split() and "data-category" in attrs:
            self.affiliate += 1
            self.categories.append(attrs["data-category"])

    def handle_data(self, data):
        if self.capture:
            setattr(self, self.capture, getattr(self, self.capture) + data)

    def handle_endtag(self, tag):
        if (tag == "title" and self.capture == "title") or (tag == "h1" and self.capture == "h1"):
            self.capture = None

urls = [e.text for e in ElementTree.parse(root / "sitemap.xml").findall(".//sm:loc", ns)]
for url in urls:
    path = url.split("/kasegu-tools/", 1)[1]
    rel = Path(path) / "index.html" if path.endswith("/") else (Path(path) if path else Path("index.html"))
    parser = Metadata()
    parser.feed((root / rel).read_text(encoding="utf-8"))
    print(rel.as_posix(), len(parser.description), parser.title.strip(),
          parser.h1.strip(), ",".join(dict.fromkeys(parser.categories)) or "なし",
          sep="\t")
print("URL数:", len(urls))
PY
```
